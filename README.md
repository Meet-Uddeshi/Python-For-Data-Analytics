
# Python For Data Analytics

This repository to learn python for data analytics from basics to advance. This repo includes all programs, code and project for data analytics. It also includes data cleaning, data preprocess and up to 90% automation for those steps.



## Set Up & Installations:
Note: While installing always check "Add to Path" checkbox to give path in environment variables in your local device.
- Download and install python stable version 3.11.x.
- Download and install git.
- Download and install any IDE.
## Run Locally

Clone the project

```bash
  git clone https://github.com/Meet-Uddeshi/Python-For-Data-Analytics
```

Go to the project directory

```bash
  cd Python-For-Data-Analytics
```

Install uv package manager

```bash
    pip install uv
```

Create virtual environment

```bash
    uv venv
```
Activate virtual environment
```bash
    ./.venv/Scripts/Activate
```
Initialize the project

```bash
    uv init 
```

Install dependency
```bash
    uv pip install -r requirements.txt
```



## Tech Stack

**Programming Language:** Python
